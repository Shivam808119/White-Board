# Board

## Publish

Upload **all files in this folder** to the root of your GitHub repository. In Settings → Pages, select “Deploy from a branch”, branch `main` and folder `/ (root)`. Open the HTTPS address GitHub provides. If updating an existing site, replace the old files, include the new files, and allow a few minutes for Pages to update.

## Install on your phone

Open the published HTTPS address in Chrome on Android and choose **Install app** or **Add to Home screen** from the browser menu. On iPhone, open it in Safari, tap Share and choose **Add to Home Screen**. Open Board from the new icon. Browser support and menu wording can vary. A local file cannot be installed this way.

## Connect phone and laptop

1. Open the published site on the laptop and leave it open.
2. Select **Share board** and copy or send the link to your phone.
3. Open the installed app on your phone, select **Join**, and paste the complete link. Alternatively, open the link in the phone browser.
4. Wait until both say **Connected**, then write on the phone. Pen, eraser, size, undo, clear, and fullscreen are in the interface. On iPhone, the installed home-screen app provides a larger view where browser fullscreen is unavailable.

The same random link gives access to the board; only share it with people you trust. Both devices need an internet connection and the first device should stay open. Drawing is stored locally on each device, but it is not a cloud backup. If the connection drops, wait for it to reconnect before continuing: reconnecting restores the host's version and may replace changes made on the disconnected device. The PeerJS public signaling service and the network must be available; restrictive networks can prevent the connection, and live drawing can have delay. Reload the laptop first and then the phone if necessary. Offline launch may work after a successful online visit, but live sharing requires internet.
